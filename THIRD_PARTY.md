# Third-party software

The Android shell uses Capacitor (MIT) and its official native plugins under their distributed licenses. The game updater uses unmodified `@capgo/capacitor-updater` 8.54.0, licensed under MPL-2.0. Source and license: https://github.com/Cap-go/capacitor-updater/tree/8.54.0 . The published npm package includes its license; no upstream plugin source has been modified in this repository. Dependency details and exact versions are recorded in package-lock.json.

Headings and numbers use the Oswald typeface (Vernon Adams and contributors), bundled from `@fontsource/oswald` 5.3.0 under the SIL Open Font License 1.1. The font files ship inside the game so it works offline.
